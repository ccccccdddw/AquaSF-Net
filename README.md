# OrnFish: A Shallow-Water Fish Detection Dataset

OrnFish is a fish object detection dataset developed to support research on visual detection in challenging shallow-water imaging conditions. It covers diverse visual disturbances, including uneven illumination, motion blur, occlusion, water-ripple interference, and complex backgrounds.

> **Release status:** A **partial release** of OrnFish is currently available. The **complete dataset will be released after the associated paper is formally published**.

## Dataset Overview

1. Pictus catfish
2. Tiger silver dollar
3. Orange chromide
4. Archerfish
5. White cloud goldfish

The images were collected from aquarium footage and selected to reflect challenges encountered in shallow-water fish detection.
